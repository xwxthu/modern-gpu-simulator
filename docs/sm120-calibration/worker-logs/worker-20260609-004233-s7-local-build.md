  `GPGPUSIM_CONFIG=gcc-13.3.0/cuda-13010/release` from the actual nvcc release.

  trace protobuf objects before building/linking GPGPU-Sim.
- App setup is the existing gpu-app collection flow:
  `source simulator-remodeled/gpu-app-collection/src/setup_environment`, then
  build the needed app target with its existing Makefile/common.mk.
