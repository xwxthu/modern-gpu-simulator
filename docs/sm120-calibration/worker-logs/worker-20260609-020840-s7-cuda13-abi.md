## Root Cause Addressed

The CUDA 13.1 backprop binary has `NEEDED libcudart.so.13` and undefined CUDA
runtime symbols versioned as `@libcudart.so.13`, including
`__cudaGetKernel@libcudart.so.13` and
`__cudaLaunchKernel@libcudart.so.13`. The previous GPGPU-Sim runtime build only
provided `libcudart.so` plus aliases through `libcudart.so.12.0`, had no
`libcudart.so.13` version node, and did not define `__cudaGetKernel`.

CUDA 13 headers show the compiler-generated triple-chevron launch path calls:

- `__cudaGetKernel(cudaKernel_t *, const void *)`
- `__cudaPopCallConfiguration(...)`
- `__cudaLaunchKernel(cudaKernel_t, dim3, dim3, void **, size_t, cudaStream_t)`

GPGPU-Sim already keys registered kernels by the host function pointer, so the
minimal compatibility layer treats the CUDA 13 `cudaKernel_t` handle as the
same opaque host function pointer inside this runtime and then forwards to the
existing launch path.

## Changes

- `simulator-remodeled/gpu-simulator/gpgpu-sim/Makefile`
  - Adds `CUDART_SONAME`, preserving `libcudart.so` for older builds and using
    `libcudart.so.13` when `CUDART_VERSION >= 13000`.
  - Adds the `libcudart.so.13 -> libcudart.so` alias.
- `simulator-remodeled/gpu-simulator/gpgpu-sim/linux-so-version.txt`
  - Adds a `libcudart.so.13` version node.
- `simulator-remodeled/gpu-simulator/gpgpu-sim/libcuda/cuda_api_object.h`
  - Exposes `kernel_config::shared_mem()` so CUDA 13 pop-call configuration can
    return the full launch tuple.
- `simulator-remodeled/gpu-simulator/gpgpu-sim/libcuda/cuda_runtime_api.cc`
  - Implements `cudaGetKernel` for CUDA 12+ as a host-function-pointer handle.
  - Implements CUDA 13 `__cudaGetKernel` and `__cudaLaunchKernel` forwarding to
    the existing GPGPU-Sim launch path.
  - Makes `__cudaPopCallConfiguration` populate grid/block/shared memory/stream
    from the launch stack.
- `simulator-remodeled/util/job_launching/run_simulations.py`
  - Copies `libcudart.so.*` aliases into `gpgpu-sim-builds` alongside
    `libcudart.so`, preserving symlinks, so run dirs do not fall back to system
    CUDA for `libcudart.so.13`.
